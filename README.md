A single quiet scene: stars appearing one by one over a ridge, a valley
settling, one small window of light going out, and a mountain holding its
dark beneath a sky that was there long before the valley had a name. The
text slows as it goes — the motions space out, the light fades, and the
last line leaves the sky still going on past the final word, larger than
the little light it outlasts.

Run `main.py` and it writes the text to `entry.txt` inside the directory
named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The program uses only
the Python standard library and is fully deterministic: two runs produce
byte-identical output.
